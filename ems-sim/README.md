# 救急隊 想定訓練シミュレータ(iPad対応 PWA)

救急隊の想定訓練用ソフトです。**指令 → 現着(現場状況) → 観察・処置 → 搬送 → 引継ぎ**を、
音声読み上げ(指令・現場状況・傷病者/家族の声・バイタル)で進行します。

## 特長
- **13想定**：呼吸困難(喘息/心不全/COPD/アナフィラキシー)、意識障害(低血糖/脳卒中/熱中症)、小児けいれん、腹痛(大動脈瘤破裂/異所性妊娠)、胸痛(心筋梗塞)、心停止(VF)、外傷(大出血)
- **役割別の操作**：隊長／救急隊員／機関員のタブごとに行動を選択(現場の分担どおり)
- **バイタルは測定したときだけ表示＆読み上げ**。処置で状態が改善、放置・誤処置で悪化し、測定済みの値は自動更新
- **その場で指導**：不適切な対応は「いや、これはこうですよ」と即時に表示・音声で指摘(特定行為の指示漏れ、禁忌の体位、COPDの高流量酸素 など)
- **振り返り画面**：得点、重要項目の漏れ、役割別チェックリスト、現場滞在時間、時系列
- **指導者パネル**：正解・真のバイタル表示、患者状態の手動切替、患者/家族の声を自由入力で読み上げ
- 音声は端末内蔵の日本語音声(Web Speech API)。オフライン動作(PWA)

## iPadで使う
このフォルダ(`ems-sim/`)をHTTPSで公開し、Safariで開いて「共有 → ホーム画面に追加」。
(例：GitHub Pages / Netlify / 社内サーバ。ローカル確認は `python3 -m http.server` )
- マナーモードを解除し音量を上げる。音声はボタン操作後に再生される
- 日本語の声：設定 → アクセシビリティ → 読み上げコンテンツ → 声 → 日本語

## 想定の追加・編集
`scenarios.js` の `SCENARIOS.push({...})` を真似て追加します(指令文・現場状況・バイタル(initial/improved/worse)・
所見・必須行動 `req`・禁忌 `avoid`・状態遷移 `transitions`・悪化条件 `worsen`)。
行動の種類は `ACTIONS` で追加できます。

## 注意
訓練用教材です。内容は一般的な知見に基づく例であり、**各地域のMCプロトコル・指導医の監修のもとで調整してください**。

## Macで試す(まずはここから)
1. このフォルダ(`ems-sim`)をMacに置く(ZIPを解凍、または `git pull`)。
2. **`start-mac.command` をダブルクリック**。ブラウザで画面が開きます。
   - 「開発元が未確認」と出たら、右クリック → 開く。
   - うまく動かないときは `index.html` を直接Safariで開いてもOKです。
3. Safari推奨(日本語の音声が自然)。音量を上げて「指令を聞く」を押すと読み上げが始まります。
