# 救急隊 想定訓練シミュレータ(iPad対応 PWA)

救急隊の想定訓練用ソフトです。**指令 → 現着(現場状況) → 観察・処置 → 搬送 → 引継ぎ**を、
音声読み上げ(指令・現場状況・傷病者/家族の声・バイタル)で進行します。

## 特長
- **13想定**：呼吸困難(喘息/心不全/COPD/アナフィラキシー)、意識障害(低血糖/脳卒中/熱中症)、小児けいれん、腹痛(大動脈瘤破裂/異所性妊娠)、胸痛(心筋梗塞)、心停止(VF)、外傷(大出血)
- **役割別の操作**：隊長／救急隊員／機関員のタブごとに行動を選択(現場の分担どおり)
- **バイタルは測定したときだけ表示＆読み上げ**。処置で状態が改善、放置・誤処置で悪化し、測定済みの値は自動更新
- **その場で指導**：不適切な対応は「いや、これはこうですよ」と即時に表示・音声で指摘(特定行為の指示漏れ、禁忌の体位、COPDの高流量酸素 など)
- **振り返り画面**：得点、重要項目の漏れ、役割別チェックリスト、現場滞在時間、時系列
- **指導者パネル**：正解・真のバイタル表示、患者状態の手動切替、患者/家族の声を自由入力で読み上げ
- 音声は端末内蔵の日本語音声(Web Speech API)。オフライン動作(PWA)

## 🎧 音声のみモード(耳だけで訓練)
ホームの「音声のみモード」にチェックして開始(訓練中も上のボタンで切替可)。
**ボタン・バイタル・ログ・患者情報をすべて隠し**、丸いボタンだけの画面になります。
指令・現場状況・傷病者/家族の声・隊員の報告(血圧138の84 など)を**耳で聞いて、頭の中で患者像をつくり**、口頭で指示します。
- 丸いボタンをタップ → 話す → 隊員/機関員/家族が音声で返答
- 「**もう一度言って**」直前の返答を繰り返す／「**バイタルをまとめて**」測定済みの値を再読み上げ／「**患者の様子は**」／「**何分経った**」／「**ヘルプ**」で指示の例を読み上げ
- 聞き取れなかったときの確認用に「字幕:ON」で文字表示も可能(指導者・確認用)
- 訓練終了後の振り返り画面で、実施内容・見落とし・時系列がすべて見られます

## 🔧 音声がうまく動かないとき
画面の「🔧 診断」(ホーム右上の「音声診断」)で、HTTPS・日本語の声・音声認識の有無を確認し、読み上げ/聞き取りのテストができます。
- **ホーム画面に追加したアプリから開くと、iPadでは音声認識が使えないことがあります。Safariの通常のタブで開いてください**
- 読み上げが聞こえない → マナーモード(消音)解除・音量アップ
- マイクのエラー → Safariの「ぁあ」→「Webサイトの設定」でマイク許可。設定でSiri(音声入力)をON
- 自動の聞き取り再開(常時聴取)はiPadで制限されることがあります。その場合は丸いボタンをタップして話してください
- どうしても認識できない場合は、**入力欄のキーボードのマイク🎤**で話して「送信」でも操作できます

## 音声で進める(口頭指示・口頭報告)
画面中央下の **🎤 話す** を押して話すと、隊長の指示として解釈されます(キーボード入力欄でも同じ)。
- 例：「**隊員、バイタル測定**」→「救急隊員、了解」→ 隊員が「呼吸数32回、脈拍128回、血圧138の84…」と**音声で報告**
- 「血圧は?」「SpO2測って」「酸素10リットル」「鼻カニュラで酸素2リットル」「半坐位にして」「静脈路確保」
- 「**機関員、ストレッチャー準備**」「出発して」「経路確認」「搬送決定」「病院に連絡して」
- 傷病者・家族への問いかけ：「**どうしましたか**」「アレルギーは?」「持病は?」「いつからですか」「ご家族に話を聞いて」→ 本人/家族の声で返答
- 「もう一度言って」で直前の発話を再生。「現着」と言うと現場へ到着
- 「**常時聴取**」をONにすると、読み上げが終わるたびに自動で聞き取りを再開します(読み上げ中はマイクを止めるので自分の声を拾いません)
- 担当違いの指示(機関員に「血圧」など)は、代わりに実施しつつ「指導(参考)」を表示します
- 使えるブラウザ：Safari(Mac/iPad)・Chrome。初回にマイクの許可が必要。Safariは「システム設定 → キーボード → 音声入力」(または Siri)がONである必要があります
- 認識はキーワード方式です。聞き取れない場合は「聞き取れませんでした」と返すので、言い換えるか入力欄を使ってください(例の言い回しは `app.js` の `VR` / `QA` 表で追加できます)

## iPadで使う
このフォルダ(`ems-sim/`)をHTTPSで公開し、Safariで開いて「共有 → ホーム画面に追加」。
(例：GitHub Pages / Netlify / 社内サーバ。ローカル確認は `python3 -m http.server` )
- マナーモードを解除し音量を上げる。音声はボタン操作後に再生される
- 日本語の声：設定 → アクセシビリティ → 読み上げコンテンツ → 声 → 日本語

## 想定の追加・編集
`scenarios.js` の `SCENARIOS.push({...})` を真似て追加します(指令文・現場状況・バイタル(initial/improved/worse)・
所見・必須行動 `req`・禁忌 `avoid`・状態遷移 `transitions`・悪化条件 `worsen`)。
行動の種類は `ACTIONS` で追加できます。

## 注意
訓練用教材です。内容は一般的な知見に基づく例であり、**各地域のMCプロトコル・指導医の監修のもとで調整してください**。

## Macで試す(まずはここから)
1. このフォルダ(`ems-sim`)をMacに置く(ZIPを解凍、または `git pull`)。
2. **`start-mac.command` をダブルクリック**。ブラウザで画面が開きます。
   - 「開発元が未確認」と出たら、右クリック → 開く。
   - うまく動かないときは `index.html` を直接Safariで開いてもOKです。
3. Safari推奨(日本語の音声が自然)。音量を上げて「指令を聞く」を押すと読み上げが始まります。
