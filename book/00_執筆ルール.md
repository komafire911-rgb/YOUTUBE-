# 執筆ルール(全担当共通)

書名: 『やる気がなくても動ける 脳科学の「5分習慣」』 副題: お金・人間関係・自己肯定感の悩みが軽くなる30日
目次: book/06_タイトルと目次_改訂版.md を必ず読む。素材の棚卸し: book/01_content_inventory.md(リスク欄が重要)。

## 読者と約束
- 読者: 30〜50代。頑張っても続かない、お金・人間関係・自己肯定感の悩みがある。引き寄せには興味があるが半信半疑。
- 約束は「悩みが軽くなる」「行動が1つ変わる」まで。「解決する」「稼げる」「治る」「必ず」は書かない。

## 文体(著者かみき♪の声)
- です・ます調。やさしく、寄り添う。専門用語は一度だけ平易に説明し、比喩を使う(脳=ビビりな警備員 など。比喩は本全体で「警備員」「カーナビ」の2つに絞る)
- 免責型の入り方を多用: 「それはあなたの意志が弱いからではありません」
- 1つの節は1つのことだけ。見出し→共感→仕組み→実践の流れ。段落は短く
- 動画台本の「次回予告」「チャンネル登録」「LINE誘導」「BGM指示」「時間表記」は書かない

## 章の型(必ずこの順)
1. 冒頭の共感の問い(2〜3行)と「この章を読むとできること」(箇条書き1〜2個)
2. 本文(3〜4節)
3. 【ワーク】(所要時間を明記。1〜5分、手順は3ステップ以内、飛ばしてもOKと書く)
4. 「脳科学メモ」(囲み): 根拠の強さを★で表示 ★研究で確認/★★有力な仮説/★★★体験談・経験則
5. 師匠かみき×弟子りんじの対話コラム(1つ、300〜500字、会話形式)
6. 章末: 「できたか」確認1行(例: 今日の5分、やれた? ○/△)

分量: 各章 5,000〜7,000字(日本語)。

## 根拠の扱い(最重要。違反すると本の信頼が崩れる)
- 使ってはいけない: 江本勝の水の結晶、528Hz/DNA修復、波動・周波数・量子・集合無意識で水や現実が変わる話、ソルフェジオ、パワーポーズの効果(カーニー)、メラビアンの法則を「93%」と言う使い方、「潜在意識が95%」「0〜7歳シータ波」「400億ビット」「UCLA40%」等の出典不明の数字
- 「脳は何%使っていない」「右脳左脳」「爬虫類脳」などの俗説も使わない
- 具体的な研究・人物名・数字を書くのは、確実に実在し内容を正確に言えるものだけ。迷ったら固有名詞と数字を出さず「〜という研究があります」「〜と言われています」と一般化し、脳科学メモに「要出典確認」と書く
- 医療・メンタルヘルスの断定は禁止。つらさが強い場合は専門家や医療機関に相談を、と一言入れる
- 体験談・事例は創作の場合「※仮名の再構成です」と明記。実在の人物の実話として書かない
- 水は「習慣のきっかけ」「マインドフルネスウォーター(水を五感で味わう)」としてだけ使う
- 「引き寄せ」「波動」という言葉は本文では原則使わない(使う場合は「そう呼ばれてきたもの」と距離を置く)
- お金の章は投資助言ではない旨、効果の個人差を書く

## 出力
- 指定されたファイルに Markdown で保存(book/manuscript/ 配下)。章ごとに1ファイル
- 最後に、書いた章の字数、「要出典確認」とした箇所の一覧、素材が足りず推測で補った箇所を報告
- git操作は不要
