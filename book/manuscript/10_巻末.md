## 5 読む順番ガイドと、悩みタイプの解説(序章の続き)

序章の「ひと言処方」の続きです。自分のタイプをもう少し知りたい方は、どうぞ。

### タイプ別 読む順番ガイド

第1章は、どのタイプの方も最初に読んでください。その後は、次の順番がおすすめです。

| タイプ | おすすめの順番 |
|---|---|
| **お金型** | 第1章 → 第2章 → **第7章** → 第3章 → 第4章 → 第5章 → 第6章 |
| **人間関係型** | 第1章 → **第6章** → 第2章 → 第5章 → 第3章 → 第4章 → 第7章 |
| **やる気型** | 第1章 → **第3章** → 第5章 → 第2章 → 第4章 → 第6章 → 第7章 |
| **複合型** | 第1章 → 上位2つのタイプの太字の章を先に → 残りは気になる順 |
| **三拍子型** | 第1章 → 第2章 → 第3章 → 気持ちが動いた章から |

### タイプごとの解説

**お金型** 金額そのものより、「足りないかもしれない」という感覚に反応しやすいタイプです。だらしないのではありません。脳は「失うかもしれないもの」に敏感だと言われていて、お金はその代表なのです。最初の課題は、お金の不安を「大きな塊」から「小さな事実」に戻すこと。いきなり貯金や投資の話はしません。

**人間関係型** 相手の気持ちを察する力が高いタイプです。頼まれると断れず、帰宅後にどっと疲れる。心が弱いのではなく、気づかいのアンテナが敏感なだけ。最初の課題は、自分を守る「小さな線」を引く練習です。

**やる気型** やりたい気持ちはあるのに、体が動かないタイプです。動けない自分を責めて、さらに動けなくなりやすい。やる気は、小さく動いたあとについてくることが多いもの(第3章)。最初の課題は、「やる気を出す」をいったん手放し、動き出しのハードルを極限まで下げることです。

### 複合型は、悩みがつながっているサイン

1つのタイプにきれいに収まる方は、あまり多くありません。悩みは、つながっているからです。

- **お金型×人間関係型** 気をつかって出費が増えやすい組み合わせです。「断る」と「お金を守る」はセットなので、第6章と第7章を交互にどうぞ
- **お金型×やる気型** 不安が大きいほど、家計の見直しに手がつかなくなります。小さなワークから始めましょう
- **人間関係型×やる気型** 気づかいで力を使い切りやすい組み合わせです。動けないのは、怠けではなく**疲れているサイン**かもしれません。休むこと、線を引くことから

### 根拠がはっきりしないため、断定を避けた話

本書では、出典を確かめられなかった話は、固有名詞や数字を出さずに書くか、使わないことにしました。主なものを挙げます。

- 「作業興奮」(第3章): クレペリンの作業曲線の研究(Kraepelin, 1902)はありますが、「作業興奮」という考え方との関係は確かめられていません。本文では「〜という見方があります」とし、【経験則】にしています。
- 「小さな行動なら不安反応が出にくい」(第1章): 直接確かめた研究が見つからず、【経験則】にしています。
- 「課題の分離」(第6章): アドラー心理学の考え方として、日本で広く知られるようになった表現として紹介しています。

## 9 著者紹介

**かみき♪**

脳科学研究家。YouTubeチャンネル『楽々脳活』で、脳の仕組みをやさしく伝える動画を発信している。

20代でナポレオン・ヒルの『思考は現実化する』という本に出会い、読書嫌いだったにもかかわらず、アンダーラインを引きながら読みふける。50代で苫米地英人さんの話を聞き、若いころ感じていたことが脳の仕組みとして説明され、腑に落ちたことから、脳の仕組みに夢中になる。

『楽々脳活』では、約1年、毎日動画を投稿。師匠が弟子に教えるドラマ仕立てなど、伝え方も「実験」として試している。

何でも「実験」のつもりで試してみるタイプ。禁酒を「どれだけできるかの実験」として始めたところ、1年続いた。タバコもやめた。
