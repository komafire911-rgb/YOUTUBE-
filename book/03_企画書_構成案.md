# 書籍企画書・構成案(編集長/企画担当)

元データ: 01_content_inventory.md(台本27本の棚卸し)、02_market_research.md(市場リサーチ)、Drive上の既存草稿「楽々脳活の本」(5章)

## 1. 企画の核

- 著者: かみき♪(脳科学研究家・YouTube「楽々脳活」)
- 仮タイトル: **『やる気がなくても、人生は変わる 脳にまかせる「楽々脳活」習慣』**
- 副題案: 意志力ゼロから始める、言葉・お金・人間関係の脳のクセ直し
- 一言コンセプト: 「うまくいかないのは、あなたのせいではなく脳の仕組み。だから頑張らずに、脳のクセを直す」
- 想定読者: 30〜50代。頑張っているのに変われない/お金・自己肯定感・人間関係に悩む人。引き寄せや波動には興味があるが、スピリチュアル一辺倒は信じきれない「半信半疑」層(note収益化計画の読者像とも一致)
- ポジショニング(リサーチ結果より): 「脳科学×引き寄せ」は飽和ぎみ。差別化は**「研究で言えること/仮説/体験談」を線引きして示す誠実さ**と、免責型フック(「あなたのせいではない」)、章末ワーク。

## 2. 構成の方針

既存草稿は「運→波動→潜在意識→お金→愛される脳」の5章。台本の棚卸しで見えた7クラスターと突き合わせ、**悩みの深い順(変われない→言葉→注意→行動→感情→人間関係→お金)**に再編する案を推す。

| 章 | テーマ(クラスター) | 主な台本素材 | 章末ワーク |
|---|---|---|---|
| はじめに | あなたのせいではない | 免責フック全般 | - |
| 1 | なぜ変われないのか(ホメオスタシス・扁桃体) | 変われない脳系 | 小さな一歩チェック |
| 2 | 言葉と脳(セルフトーク、感情ラベリング) | 言葉で人生が変わる習慣ほか | 言葉の置き換え表 |
| 3 | 運の正体はRAS(注意のフィルター) | 既存草稿1章、目標系 | ツイてる脳ノート |
| 4 | 小さく始める習慣術(5分ルール、ドーパミン) | モチベーション6部作 | 5分ルール習慣表 |
| 5 | 感情・ストレス・体を整える(マインドフルネスウォーター) | 水シリーズを習慣トリガーとして再設計 | 呼吸+水の1分ワーク |
| 6 | 人間関係の脳内ルール(ミラーニューロン、共鳴) | 波動・共鳴5部作、人間関係6部作 | 付き合う5人の棚卸し |
| 7 | お金の器(収入/流入/需要/貯蓄の4つの器、ブロック3診断) | お金のブロック解除、お金の器 | お金のブロック診断 |
| おわりに | 楽して楽しく生きる | 既存草稿おわりに | 30日プラン |

補助要素
- 師匠かみき×弟子りんじの対話コラム(各章1ページ)
- 「脳科学メモ」囲み(根拠の強さを★で表示: ★研究で確認/★★有力な仮説/★★★体験談)
- 巻末: 30日チェックシート、参考文献

## 3. 台本→書籍のルール

1. 水の結晶(江本勝)を**根拠として使わない**。水は「習慣のトリガー・マインドフルネスウォーター」へ再設計。使う場合はコラムで「科学的合意はない」と注記。
2. 528Hz/DNA修復、「日本人にしか使えない周波数」、量子・集合無意識で水が変わる等の回は不採用。
3. 出典不明の数字(UCLA 40%、95%潜在意識、400億ビット等)は一次情報で確認するまで本文に載せない。
4. 医療・効果保証の断定表現(「治る」「必ず」)は「〜という研究がある」へ。
5. 体験談は仮名で再構成と明記。AI応答の残骸、同話の複数版、人物名の揺れは編集時に統一。
6. 営業心理・ストーリー型(全24話)は別企画として分離。

## 4. 出版ルート(推奨)

- 第1段階: Kindle(KDP)で試し読み版(1〜2章+ワーク)を先行公開 → 反応を企画書の材料にする
- 第2段階: 商業出版の持ち込み(脳科学・実用書に強い出版社へ、本書の企画書+Kindle実績)
- 並行: noteで「年収は付き合う5人の平均」など章の一部を記事化(収益化計画の1本目)
- 注意: KDPの70%ロイヤリティは価格250〜1,250円+KDPセレクト登録が条件(公式ヘルプ確認済み)。商業出版の印税は新人で約8〜10%(解説記事ベース、要再確認)。
